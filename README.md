# calypso-factory

Start with `CLAUDE.md` (project brief, loaded automatically by Claude Code), then `docs/architecture.md` and `docs/workbench-reference.md`.

## Setup

1. Put Config Workbench exports in `exports/<client>/`. The folder is git-ignored.
2. Unpack the Config Workbench release zip into `vendor/configworkbench/`. Also git-ignored; it holds the API docs, schemas and config files referenced in `docs/workbench-reference.md`.
3. Run `claude` in this folder.
